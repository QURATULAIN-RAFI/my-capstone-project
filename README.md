# My Capstone Project

## Description

This is my capstone project for the AI-assisted development track.

The project will be developed using AI-assisted development practices with Cursor.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS version recommended)
- [Git](https://git-scm.com/)

### Setup

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Change into the project directory:

   ```bash
   cd my-capstone
   ```

There are no npm dependencies to install yet. The project does not include a `package.json` at this stage.

### Usage

Run the entry point with Node.js:

```bash
node src/index.js
```

You should see:

```
Capstone project started!
```

## Project Goal

The goal of this project is to build a task management application that helps users organize and manage their daily tasks.

The application will help users create tasks, set priorities and deadlines, track task progress, and keep their work organized in one place.
